# Visuels des jeux

Dépose ici (sur GitHub : *Add file → Upload files*) les images des jeux. Elles sont détectées d'après leur nom :

| Fichier | Rôle |
| --- | --- |
| `tarot-bg.jpg`, `skyjo-bg.jpg`, `sixquiprend-bg.jpg`, `free-bg.jpg` | Visuel de fond de la carte du jeu, affiché à droite avec un dégradé qui fond vers la couleur du jeu côté titre |
| `tarot-logo.png`, `skyjo-logo.png`, `sixquiprend-logo.png`, `free-logo.png` | Logo du jeu, posé à droite de la carte par-dessus le fond, pour appuyer le visuel (le titre reste en texte à gauche ; idéalement sur fond transparent) |

Formats acceptés : jpg, jpeg, png, webp, svg. Un visuel de fond de 800 × 400 px suffit ; garde chaque fichier sous 300 Ko
pour que le site reste léger et utilisable hors ligne. Un jeu sans fichier garde son illustration par défaut.
